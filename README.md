# AP-CSP-Final-Project
Simple app in CMU CS Academy that chooses an outfit based off of the temperature and the weather options that are selected by the user. At the beginning of the app, the user is presented with a series of propmts that are all on a single screen. The user is supposed to either begin by clicking on one of the weather options, or sliding to shift the value of the temperature on the program. After the choices are selected, a text box below thd options will be presented to the user and the user will be able to get feedback on what they should wear. A locking button marked by a green check box with an X in the middle locks the temperature value in place when it is clicked. The user is still able to change the value of the weather but the temperature value is immovable, as well as making the button red. A second click on the button resets the user interface and allows for the program to be run once again.
